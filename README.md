# Psycho Program — адмін-панель (прототип для демо)

Прототип адмін-панелі для практиків (психологи, коучі) у стилі Quenza.

Репозиторій містить три частини:
- **Адмін-панель** (корінь репозиторію) — React + TypeScript + Tailwind для психолога. Працює з реальним API: екран входу, JWT-сесія, усі дані через бекенд.
- **Бекенд** (`server/`) — REST API на Node + Express + Prisma + PostgreSQL з авторизацією JWT і ролями психолог/клієнт. Документація: [`server/README.md`](server/README.md).
- **Клієнтський застосунок** (`mobile/`) — нативний мобільний застосунок на Expo / React Native: вхід за запрошенням, програми з активностями, щоденник. Документація: [`mobile/README.md`](mobile/README.md).

## Запуск (потрібні обидві частини)

**1. Бекенд:**
```bash
cd server
cp .env.example .env   # вкажіть DATABASE_URL і JWT_SECRET
npm install
npm run migrate:dev    # створює таблиці
npm run db:seed        # демо-дані
npm run dev            # API на http://localhost:4000
```

**2. Фронтенд** (в окремому терміналі, з кореня репозиторію):
```bash
npm install
# за замовчуванням фронтенд звертається до http://localhost:4000;
# щоб змінити — cp .env.example .env і задайте VITE_API_URL
npm run dev            # http://localhost:5173
```

Увійдіть демо-акаунтом психолога: **demo@psychoprogram.com** / **demo1234**.

Деталі API, ролі та деплой у хмару — у [`server/README.md`](server/README.md). Готовий Render-блупринт: [`render.yaml`](render.yaml).

> **Деплой у проді:** фронтенд на GitHub Pages збирається з адресою API зі змінної репозиторію `VITE_API_URL` (Settings → Secrets and variables → Actions → Variables). Поки бекенд не задеплоєний і змінна не задана, опублікований фронтенд намагатиметься звертатися до `localhost:4000`.

## Розділи

| Вкладка | Що вміє |
|---|---|
| **Клієнти** | список з пошуком і фільтром за статусом (активний / запрошено / архів), запрошення клієнта, профіль з вкладками: активності, програми, ресурси, задачі, нотатки; архівація |
| **Групи** | створення груп, керування учасниками, **авто-надсилання** активностей і програм новим учасникам групи |
| **Активності** | «Мої» + бібліотека готового контенту (копіювання до своїх), конструктор елементів (секції, текст, запитання, шкала, вибір варіанту, відео, зображення), **page breaks** (ручні розриви сторінок з превʼю пагінації), надсилання клієнту/групі |
| **Програми** | конструктор pathway: кроки-активності з правилами доставки (одразу / через N днів після завершення попередньої / через N днів після старту), надсилання клієнту або групі |
| **Ресурси** | файли та посилання, шерінг з окремими клієнтами |
| **Задачі** | робочий список практика: дедлайни, прив'язка до клієнта, відкриті/виконані |
| **Нотатки** | приватні нотатки (загальні або про клієнта), фільтр за клієнтом |
| **Щоденник** | стрічка щоденних записів, які клієнти ведуть у мобільному додатку (для психолога — лише читання): настрій, теги, групування за днями, фільтри за клієнтом/настроєм, позначення «переглянуто» та відповідь клієнту. Статистика: всього записів, за тиждень, не переглянуто, середній настрій. Доступний також як вкладка у профілі клієнта |

Додатково реалізовано за довідкою Quenza:

- **Перегляд завершеної активності** — відповіді клієнта по елементах (профіль клієнта → Активності → «Переглянути відповіді»)
- **Гілки коментарів (threaded comments)** — під кожним елементом відповіді та загальна гілка до активності
- **Повторне відкриття завершеної активності** — кнопка «Відкрити для оновлення»
- **Логіка page breaks**: вимкнено — кожен елемент на окремій сторінці; увімкнено — елементи групуються до розриву, секція завжди починає нову сторінку; прогрес рахується за елементами
- **Авто-надсилання у групах**: при додаванні нового учасника обраний контент надсилається йому автоматично
