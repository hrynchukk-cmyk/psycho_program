# Psycho Program — клієнтський застосунок (Expo / React Native)

Нативний мобільний застосунок для клієнтів (пацієнтів). Клієнт заходить за
запрошенням, бачить призначені програми й активності, виконує їх і веде
щоденник. Працює з тим самим бекендом, що й адмін-панель (`/api/client/*`).

## Можливості

- **Вхід / активація за запрошенням** — клієнт активує акаунт за email, на який
  його запросив психолог, або входить наявним акаунтом.
- **Головна** — призначені програми (з кроками) та активності зі статусами
  (нове / в процесі / завершено).
- **Активність** — перегляд елементів, заповнення відповідей (короткі/розгорнуті
  поля, вибір варіанту, шкала 1–10) і надсилання психологу.
- **Програма** — послідовність кроків із правилами доставки.
- **Щоденник** — щоденні записи з настроєм; видно відповіді психолога.
- **Матеріали** — файли й посилання, якими поділився психолог.
- **Профіль** — дані та вихід.

## Запуск

```bash
cd mobile
npm install
# (необовʼязково) вкажіть адресу бекенду для локальної розробки:
cp .env.example .env   # EXPO_PUBLIC_API_URL=http://<ваш-IP>:4000
npx expo start         # відкрийте у застосунку Expo Go (сканувати QR)
```

За замовчуванням застосунок звертається до задеплоєного бекенду на Render, тож
без `.env` він одразу працює з продакшн-API.

### На телефоні
1. Встановіть **Expo Go** (App Store / Google Play).
2. `npx expo start` на компʼютері → відскануйте QR камерою (iOS) або в Expo Go (Android).
3. Увійдіть демо-акаунтом: **client@psychoprogram.com** / **demo1234**.

> Для локального бекенду телефон і компʼютер мають бути в одній мережі, а в
> `EXPO_PUBLIC_API_URL` вкажіть IP компʼютера (не `localhost`).

## Складання застосунку (білд)

Через **EAS Build** (хмарна збірка Expo): `npx eas build -p android` /
`-p ios`. Потрібен акаунт Expo. Деталі — у [docs.expo.dev](https://docs.expo.dev/build/setup/).
